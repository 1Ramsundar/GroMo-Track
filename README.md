# GroMo Track

**Tagline:** Track Every Rupee. Grow Every Month.

GroMo Track is a Progressive Web Application (PWA) that helps users track daily expenses, analyze spending habits, generate reports, and manage finances with a clean and modern interface.

## Tech Stack

- React + Vite
- Tailwind CSS
- Node.js
- Express.js
- PostgreSQL (Supabase)
- JWT Authentication
- Chart.js
- jsPDF
- SheetJS
